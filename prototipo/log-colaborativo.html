Configurar log compartilhado

O log usa o JSONBin.io como banco de dados na nuvem — gratuito, sem instalar nada. Toda a equipe vê as mesmas entradas em tempo real.

PASSO 1 — Criar conta
Acesse jsonbin.io → Sign Up → crie com e-mail e senha.
PASSO 2 — Copiar a API Key
No painel → API Keys → copie a chave que começa com $2b$...
PASSO 3 — Criar o Bin
Clique em Create a Bin → cole o JSON abaixo → Create:
{"logs":[],"tarefas":[],"decisoes":[],"equipe":[],"modulos":[]}
PASSO 4 — Copiar o Bin ID
A URL do bin termina com o ID: https://api.jsonbin.io/v3/b/SEU_ID_AQUI
